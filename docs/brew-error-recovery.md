# 추출 중 물체 제거와 오류 복귀

추출 중 이전 net 무게보다 5 g 내려갔다는 이유로 baseline을 무효화하던 조건을 제거한다.
액체 감소나 센서 변동으로 net 무게가 내려가더라도 물체가 남아 있으면 계량을 계속한다.

## 물체 제거 판정

- 추출 시작 시 현재 선택된 등록 물체의 빈 무게를 세션에 고정한다.
- 제거 기준은 `min(등록 빈 무게, 시작 시 filtered gross, 시작 시 구간 평균 gross) - 1.0 g`으로
  고정한다. 등록 당시와 현재 설치의 작은 오차 때문에 시작부터 제거 조건에 걸리는 것을 막는다.
  이후 액체 추가로 기준을 올리지 않는다.
- median 3 기반 실제 gross가 이 기준 아래인 상태를 300 ms 유지하면 제거로 판단한다.
  등록 100.0 g, 시작 99.6 g이면 기준은 약 98.6 g이다. 순무게 -0.1 또는 -0.2 g은
  제거 오류가 아니다. 1.0 g 미만의 작은 감소는 제거로 간주하지 않는 절충이다.
- 추출 화면에서도 센서의 quiet 상태일 때 정지 표시 필터를 적용한다. 실제 유입이 감지되면
  움직임 표시로 전환하고 큰 변화는 즉시 표시한다. 음수 측정값을 0으로 덮어쓰지 않으며,
  표시 필터는 제거 판정·유량·기록에 영향을 주지 않는다.
- 미등록 물체는 빈 무게를 추측하지 않고 기존의 지속 near-zero 제거 판정을 사용한다.
- 센서 단절, 과부하 및 데이터 gap은 별도의 sensor fault로 계속 처리한다.
- 제거 또는 센서 오류 이후에는 물체를 다시 놓거나 센서가 복구되어도 기존 추출을
  자동 재개하지 않는다. 마지막 유효 무게를 보관하고 화면에는 무게와 유량을 사용 불가로 표시한다.

## 오류 후 복귀

화면에 오류 원인과 메인 복귀까지 남은 시간을 표시한다. 최초 오류부터 180초가
지나면 물체가 아직 있거나 센서가 계속 끊겨 있어도 메인 화면으로 직접 복귀한다.
추가 오류나 센서 복구는 타이머를 재시작하지 않는다. 오류 중 Finish를 누른 결과
화면에서도 남은 타이머는 계속 진행한다.

진행 중인 실패 세션은 복귀할 때 aborted 기록으로 한 번 저장하고 tare와 세션을
초기화한다. 이미 Finish로 저장한 결과는 중복 저장하지 않는다. 등록 물체 목록과
보정은 유지한다. 사용자의 Reset이나 새 세션 시작은 이전 오류 타이머를 초기화한다.

`brew_error_test`는 net 감소, 빈 무게 근처 잡음, 짧은 하강, 실제 제거, 역극성
보정, 180초 경계, 반복 오류, 물체가 남은 경우, Finish 후 복귀 및 중복 기록 방지를
검증한다. 등록 무게와 시작 무게가 다른 상태에서 -0.1 g과 ±0.2 g 흔들림을
10 SPS 및 약 80 SPS, 양/음 보정 극성으로 재생한다. `make preview`는 -0.1 g에서
추출 화면 유지와 오류 화면에서 메인 화면으로 실제 LVGL 전환을 확인한다.

무게 표시 전환 로그에는 `brew_error` 원인과 `removal_below` 기준을 남긴다. 작은 음수에서
오류가 계속되면 해당 로그로 제거 판정과 센서 gap/timeout을 구분할 수 있다.
